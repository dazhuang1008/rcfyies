# 中文到西班牙语日常翻译学习工具

手机优先的中文→西班牙语翻译网页，使用通用现代西语、A2-B1 常见词和简单句式。

## 文件说明

- index.html：网页界面。可放在 GitHub Pages。
- worker.js：可选的 Cloudflare Worker 代理方案；普通直连模式不需要部署。
- 翻译规则.md：本工具采用的翻译要求。

## 最简单的使用方式

1. 打开已发布的网页，点击右上角设置图标。
2. 在“TeamoRouter API Key”输入框粘贴自己的 API Key。
3. 保持默认模型或选择其他可用模型，然后点“保存”。
4. 输入中文并开始翻译。

输入时也可以点输入框下方的麦克风按钮开始中文语音识别，再点一次结束；识别文字会追加到输入框，可检查修改后再翻译。浏览器需要获得麦克风权限，并且语音识别能力依赖浏览器及其语音服务。

网页会直接请求 `https://api.teamorouter.com/v1/chat/completions`。API Key 保存在当前浏览器的本地存储中，不会写进 `index.html` 或 GitHub 仓库。每个使用者都应填写自己的 Key。

## 安全与限制

- 不要把 API Key 发到聊天、截图或公开仓库；如果曾经泄露，请先在 TeamoRouter 撤销并重新创建。
- 只在自己的设备上保存 Key。网页脚本和浏览器扩展可能访问当前站点的本地存储；清除设置会删除本机保存的 Key。
- 公开网页不会自动获得你的 Key，但任何人都能打开网页并使用他们自己填写的 Key。
- 浏览器直连要求 TeamoRouter 接口允许网页跨域请求（CORS）。如果出现跨域或 `Failed to fetch` 错误，这种直连方式无法在当前环境工作，需要使用 `worker.js` 作为服务端代理。
- 输入的中文会直接发送给 TeamoRouter 用于生成译文。翻译历史保存在当前浏览器。
- 语音识别由浏览器的 Web Speech API 提供；不同浏览器支持情况不同，语音识别可能使用浏览器厂商的在线服务。若按钮不可用，可使用手机键盘自带的语音输入。
